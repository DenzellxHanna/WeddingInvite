# Responsive design

The interface is mobile-first and will support small through large phones, tablets, 1366×768 laptops, 1920×1080 desktops, and larger monitors. The album should remain materially believable on portrait screens, while touch swipe maps to the same page navigation model as desktop click and keyboard interaction.

Feature-specific breakpoints belong with photobooth or album CSS; shared responsive rules belong in `shared/css/responsive.css`.
