# Design system

The visual identity is premium, editorial, romantic, physical, sophisticated, slightly vintage, and timeless. It is modern enough for 2028 without becoming a generic wedding template. Warm Ivory remains the primary background; the whole experience should not be dark.

| Token | Value | Role |
| --- | --- | --- |
| `--burgundy` | `#722F3E` | Primary identity color and controlled accent |
| `--navy` | `#243B5A` | Primary identity color and typography contrast |
| `--light-gray` | `#D9DCE1` | Supporting detail and subtle structure |
| `--champagne` | `#D8C29D` | Restrained metallic or foil-like detail |
| `--ivory` | `#F3F0E9` | Primary neutral and background |

Canonical tokens are defined only in `shared/css/variables.css`. Photobooth and album CSS must consume them rather than redefine wedding identity colors.

The closed album cover uses an ivory base with restrained Burgundy and Navy accents, Champagne metallic detail, Light Gray support, elegant typography, subtle texture, spine depth, and a modest embossed or foil effect. Its only wording is `D/H WEDDING`. Avoid excessive flowers, cartoon graphics, emoji, excessive gold, overly ornate Victorian styling, dates, additional names, invitation copy, or RSVP text on the cover.
